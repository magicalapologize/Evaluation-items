# 「天赋挖掘测试｜找到你的天赋领域」设计方案

## 1. 产品边界

### 1.1 产品定位

新建一个独立网页测试：`tests/talent-discovery/`。

产品正式名称：**天赋挖掘测试｜找到你的天赋领域**。

英文辅助标题：`MULTIPLE TALENT MAP`。

产品借鉴霍华德·加德纳提出的多元智能理论，用于自我观察与发展启发。页面统一把八个理论维度称为“天赋”，不把结果写成固定智力等级，也不替代心理诊断、能力考试、职业资格判断或职业决策。

### 1.2 与现有产品的关系

- 「天赋职业评估」保持原有 45 题、9 维度、职业方向模型不变。
- 新产品拥有独立的题库、数据文件、页面样式、结果记录 `productId` 和二维码。
- 「天赋职业评估」页面增加推荐入口，指向 `tests/talent-discovery/`。
- 新测试结果页可反向推荐「天赋职业评估」，但不自动跳转、不改变当前结果流程。

### 1.3 认证逻辑

新产品使用稳定英文标识：`talent-discovery`。

用户输入测试码后，仍走现有 `POST /api/verify-code` 流程。为满足“输入天赋职业评估测试码也能测试新产品”，Worker 在服务端建立授权映射：

- `talent-discovery` 当前有效码可进入新测试；
- `talent-career` 当前有效码也可进入新测试；
- 会员用户沿用现有会员自动解锁逻辑；
- 前端不写死任何真实测试码、演示码或默认码；
- 结果记录仍使用新产品自己的 `productId`，避免两款测试的历史记录混淆。

授权实现应优先复用现有 `daily_codes` 查询结构。若直接查询另一产品的当前码，必须在 Worker 中集中实现，不在两个页面之间复制测试码。

## 2. 测量模型

### 2.1 八项天赋维度

页面、题库、结果数据和海报统一使用以下名称：

| 理论维度 | 产品名称 | 观察重点 |
|---|---|---|
| 语言 | 语言表达天赋 | 用文字、语言和叙事表达想法 |
| 逻辑数学 | 逻辑推演天赋 | 发现规律、拆解问题、验证判断 |
| 空间 | 空间想象天赋 | 感知画面、布局、方向和结构 |
| 身体运动 | 身体实践天赋 | 通过动作、操作和现场实践解决问题 |
| 音乐 | 音乐节奏天赋 | 感知节拍、声音、旋律和情绪变化 |
| 人际 | 人际感知天赋 | 读懂他人、建立关系、协调互动 |
| 内省 | 内在觉察天赋 | 理解自己的情绪、动机和价值取向 |
| 自然观察 | 自然观察天赋 | 观察环境、分类事物、感知自然变化 |

理论说明固定文案：

> 本测试参考加德纳提出的多元智能理论。为了方便理解，页面把八个理论维度称为“天赋维度”。结果反映的是本次答卷中的相对倾向，不是标准化智力诊断，也不代表固定能力等级。

### 2.2 结果模型

每份报告包含：

1. 一个最佳天赋：八项维度中本次答卷得分最高者；
2. 一个辅助天赋：第二高者，用于解释最佳天赋的使用方式；
3. 八项天赋综合画像；
4. 四项活跃天赋深入分析：按得分和跨场景稳定性动态选出；
5. 一项待唤醒天赋线索：分数较低或场景信号较少，不表述为能力差；
6. 与天赋组合相关的优势职业赛道；
7. 个人竞争力说明；
8. 进阶成长方案和独立的结果提醒。

结果名称直接表明最佳天赋，不使用“某某者”式角色命名：

- 语言表达天赋
- 逻辑推演天赋
- 空间想象天赋
- 身体实践天赋
- 音乐节奏天赋
- 人际感知天赋
- 内在觉察天赋
- 自然观察天赋

最佳天赋的显示格式：

> 你的最佳天赋：空间想象天赋
> 辅助天赋：内在觉察天赋

### 2.3 计分规则

- 总题数：40 道；
- 每题 4 个选项；
- 每项天赋有 5 道主要观察题，分布在 5 个生活场景；
- 每个选项使用语义化计分矩阵，主信号建议为 `+3 / +2 / +1 / 0`，辅助信号为 `+1 / 0`；
- A/B/C/D 展示顺序随机打散，原始选项索引保留；
- 不使用“题号 + 选项序号轮转加分”；
- 每项天赋按自身题目覆盖量归一化；
- 结果判定刻度与页面展示刻度分开；
- 并列时用答案序列生成确定性指纹二次判定；
- 允许同一用户返回上一题修改，重新计算全部结果。

展示刻度只表达本次答卷内部的相对强弱。不得直接用“命中次数 ÷ 40”作为天赋百分比，也不得把低分解释为缺陷。

## 3. 题库结构

40 道题采用五个场景、八项天赋交叉覆盖：

| 场景 | 题数 | 观察方向 |
|---|---:|---|
| 学习与理解 | 8 | 吸收、记忆、解释和迁移信息 |
| 创作与表达 | 8 | 形成想法并把它表达出来 |
| 问题解决 | 8 | 面对困难时的处理路径 |
| 关系与自我 | 8 | 理解他人、觉察自己、处理分歧 |
| 日常环境与兴趣 | 8 | 生活中的自然偏好和注意对象 |

题目必须使用具体生活情境，四个选项都要合理、长度接近、没有明显正确答案。题目初稿完成后检查：

- 是否真的观察到对应天赋，而不是测社会期待；
- 是否与其他题重复；
- 是否连续多题只测同一种行为；
- 是否覆盖独处、合作、压力、学习、创作和日常环境；
- 是否存在所有人都容易选择的“安全答案”。

## 4. 报告页结构

报告页沿用现有模板的操作能力和视觉层级，但内容合并为以下九个模块。

### Hero：你的最佳天赋评估

- 产品名和英文辅助标题；
- 报告日期与编号；
- 最佳天赋、辅助天赋；
- 3 个结果标签；
- 一句话结果总结；
- 对应主天赋视觉图；
- 答卷内部相对强度。

### 01｜你的最佳天赋评估

解释最佳天赋在生活、学习和工作中的表现，列出五个场景中的主要信号，说明它更容易在哪些任务中出现，以及用户可能低估的能力。

### 02｜8 项天赋综合解读

- 八维雷达图；
- 八项横向进度条；
- 每项天赋的生活化解释；
- 高、中、待观察三档状态；
- 明确说明数值是本次答卷内部比较，不是人群排名。

### 03｜4 项活跃天赋深入分析

动态渲染四张卡片。每张卡包含天赋名称、典型场景、优势表现、过度使用后的限制和一条可执行练习。

### 04｜解锁隐藏天赋潜能

展示待唤醒天赋线索、它出现过的场景、目前未成为主导项的可能原因，以及一个 30 天低成本验证方法。不得宣称测出了用户“真正隐藏的能力”。

### 05｜规避潜在发展瓶颈

每个最佳天赋拥有独立文案，结构为“天赋优势 + 过度使用后的具体代价 + 下一次可执行的纠偏动作”。不使用通用提醒或关键词拼接。

### 06｜锁定优势职业赛道

根据最佳天赋、辅助天赋和活跃天赋组合，提供 3–5 个优先探索赛道。每个赛道包含适合的任务类型、环境提示和一个低成本验证动作。必须注明这不是固定职业结论，不重复生成「天赋职业评估」的 80 个职业地图。

### 07｜掌握天赋拓展策略

分为放大最佳天赋、连接辅助天赋、唤醒潜能天赋三类。每条策略要有触发场景、具体动作、时间边界和判断是否有效的标准。

### 08｜定位个人竞争力

用“最佳天赋 × 辅助天赋 × 适合场景”解释组合优势，避免泛泛写“你很独特”。报告要回答用户如何把天赋组合变成作品、经验或可验证成果。

### 09｜获取进阶成长方案

沿用现有结果模板的行动结构：第 1 周记录、第 2–4 周低成本尝试、第 2 个月形成可展示成果、第 3 个月复盘是否继续投入。每个最佳天赋结果有独立行动顺序、成果形式、复盘问题和“给你的提醒”。

底部保留：保存报告海报、复制结果摘要、重新测试、好评返现、测试记录和免责声明。

## 5. 文案生产与去痕流程

用户可见文案包括题目、160 个选项、八项天赋说明、结果报告、建议、90 天方案、测试码提示、推荐入口和海报文案。

处理顺序：

1. 先按理论和计分矩阵完成内容初稿；
2. 检查每题与每个选项的心理含义；
3. 使用 `humanizer-zh` 技能逐段去除 AI 写作痕迹；
4. 删除宣传式语言、空泛金句、三段式套话、过度破折号和模糊归因；
5. 保留加德纳理论边界和“相对倾向”表述；
6. 对去痕版本重新检查计分含义、结果一致性和事实边界；
7. 检查 8 个最佳天赋结果的提醒是否独立、具体、可执行。

不得编造准确率、用户数量、权威认证、心理测量信效度或“测得很准”等主张。不得使用“天生”“注定”“一定适合”等确定性表达。去痕不能把“目前较少使用”改成“能力弱”。

2. 首页/社交卡片：`1:1，1200×1200`；

## 7. 分享海报

海报使用现有 Canvas 流程，但按新产品重新排版，不把网页直接缩小。

四个区域：

1. 身份区：产品名、最佳天赋、辅助天赋、三个标签和一句话定义；
2. 数据区：完整八项天赋，使用 2×4 布局，不能只截取前几项；
3. 建议区：保留 3 条最重要的成长建议，自动换行，不截断；
4. CTA 区：新产品独立二维码、识别说明和分享引导。

二维码必须绘制进 Canvas，实际宽高建议不小于 180px。`createPosterImage()` 使用 `async` 并等待图片加载。开发后必须打开真实 PNG，检查八项天赋完整、建议不截断、二维码可识别、底部署名有足够对比度。

## 8. 验收标准

### 内容与模型

- 40 道题全部可作答，8 项天赋都有独立覆盖；
- 8 个最佳天赋结果全部可达；
- 主导与辅助天赋判定稳定；
- 4 项活跃天赋按答卷动态变化；
- 每个结果有独立的“规避潜在发展瓶颈”和“给你的提醒”；
- 八维展示不出现全部偏低或完全相同；
- 去痕后的文案仍保留理论边界和计分含义。

### 交互与授权

- 输入 `talent-discovery` 测试码可进入；
- 输入 `talent-career` 当前测试码可进入；
- 错误码、停用码、网络失败和服务异常有清晰提示；
- 会员可直接进入；
- 前端源代码没有真实测试码或演示码；
- 返回修改、重新测试、保存报告、复制摘要、好评返现和历史记录可用。

### 分布压力测试

- 全选 A/B/C/D 至少产生 3 种不同最佳天赋，理想为 4 种；
- 随机模拟至少 10 万份答卷；
- 所有 8 个最佳天赋均可达；
- 单一结果不应长期垄断；
- 相同答案序列重复计算得到同一结果。

### 响应式与海报

检查尺寸：`1440×900`、`1366×768`、`390×844`、`390×720`、`360×720`、`320×720`。

确认：

- `document.documentElement.scrollWidth <= window.innerWidth`；
- 题目、答案、按钮没有重叠；
- 结果 Hero、雷达图、八项天赋和弹窗可读；
- 弹窗支持滚动、关闭按钮、遮罩和 Esc；
- 真实 PNG 海报四区完整、二维码可识别；
- 控制台无错误。

## 9. 实施范围

用户确认本设计后，下一阶段再制定实现计划。预计涉及：

- 新建 `tests/talent-discovery/` 页面、样式、题库和模型；
- 复制并收敛现有成熟测试的会员、历史记录、结果和海报流程；
- Worker 增加产品 ID 与跨产品测试码授权；
- 首页和「天赋职业评估」页面增加推荐入口；
- 添加新产品卡片、主视觉、结果图和二维码；
- 生成内容后执行 `humanizer-zh` 去痕与人工复核；
- 编写模型测试、题库质量测试、分布模拟和 UI 验收脚本。

本设计不包含：支付系统、先测后付费解锁、心理诊断、标准化常模、复杂后台 CMS 或独立职业数据库。
