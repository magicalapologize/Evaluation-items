# 七宗罪结果页雷达图数值展示设计

## 目标

在结果页七维雷达图外围显示每个罪名对应的“倾向指数”，让用户无需对照下方排行即可读懂图形。

## 方案

采用 SVG 外圈双行标签：第一行显示罪名，第二行显示 `0-100` 倾向指数。标签继续使用现有暗红金色视觉，名称和数值保持同一轴线；数值使用更醒目的浅金色，增强扫描效率。

标签根据轴方向自动设置 `text-anchor`：顶部和底部居中，左侧右对齐，右侧左对齐。标签半径从当前雷达网格外沿扩大到安全区域，避免文字压住网格或顶点。

## 范围

- 修改 `tests/seven-sins/index.html` 的 `renderRadar(displayScores)`。
- 修改 `tests/seven-sins/style.css` 的雷达标签样式。
- 新增 UI 兼容测试，检查七个罪名和七个数值都进入 SVG 文本。
- 不修改计分、展示分、排行、海报和其他结果页模块。

## 验收标准

- 七个罪名均显示一次，七个 `0-100` 数值均显示一次。
- SVG 仍保留七条轴线、四层网格、雷达形状和七个顶点。
- 1440px、390px、320px 宽度下无横向溢出，标签不被裁切或互相覆盖。
- 现有测试全部通过，浏览器控制台无错误。
