# 社会化程度测试产品设计规格

## 产品目标

开发一款可在小红书售卖和分享的网页测试产品，用 40 道生活情境题评估用户在必要社交中的策略完整度，而不是把外向程度当作社会化程度。用户完成测试后获得综合分、五阶段定位、六维雷达图、八种人格画像之一、逐维度解析、综合评价、风险提醒和可执行的改进建议。

## 用户与边界

- 主要用户：自认为是 i 人、社交容易内耗、刚进入职场或新环境的年轻用户。
- 泛用户也可参与；题目不要求专业知识。
- 高分表示可调用的社交策略更多、更灵活，不表示更外向或更有价值。
- 结果是行为倾向与自我观察，不构成心理诊断、医学判断或对现实关系的绝对判断。
- 题目和结果文案原创重写，只吸收《社会化指南》的主题原则，不复制原文长句、品牌名或章节内容。

## 测量维度

| key | 名称 | 低分端 | 高分端 |
| --- | --- | --- | --- |
| basic | 基础互动 | 回避必要互动 | 能自然完成问候、感谢、回应和告别 |
| expression | 表达与倾听 | 不敢开口或只顾自我表达 | 能说清需求、接话、提问并认真倾听 |
| context | 情境判断 | 容易踩话题和场合雷区 | 能识别对象、边界、潜台词和场合规则 |
| boundary | 边界与拒绝 | 过度迎合或事后憋屈 | 能礼貌、清晰、坚定地拒绝和回应冒犯 |
| relationship | 关系经营 | 只在需要时联系或过度消耗 | 能稳定出现、回馈、建立信任和融入圈子 |
| stability | 能量与稳定 | 灾难化想象、透支、反复内耗 | 能规划社交电量、调节焦虑、及时恢复 |

## 题库结构

共 40 题，分为 8 个场景组，每组 5 题：

1. 日常微互动
2. 陌生人与半熟聊天
3. 倾听、接话与表达
4. 交朋友与融入圈子
5. 拒绝、请求与边界
6. 冲突、冒犯与修复
7. 职场与线上沟通
8. 社交电量与情绪稳定

每题包含一个具体情境和四个都有道理的选项。每个选项有语义计分矩阵：主维度通常为 `+3`，辅助维度通常为 `+1`，反向题通过相反向量表达。选项字母在题目间打散，不允许通过固定字母猜结果。

## 评分模型

### 原始信号

逐题将选项分数累加为六维原始信号，同时记录每个维度的可用分数上下界。模型必须校准每个维度自己的题目覆盖率，禁止直接用“命中次数 / 40”显示百分比。

### 展示分

将用户在每个维度的相对位置独立映射到 `0-100`，用于雷达图和逐维度内容。匹配分与展示分使用不同函数：匹配分服务于人格距离比较，展示分服务于用户理解。

### 综合分与阶段

综合分为六个校准展示分的等权平均，四舍五入为整数。阶段规则：

| 分数 | 阶段 | 说明 |
| --- | --- | --- |
| 0-39 | 低耗自保期 | 先完成必要互动，减少逃避和过度内耗 |
| 40-54 | 基础通行期 | 基本礼貌已具备，复杂场景仍容易卡住 |
| 55-69 | 稳定应对期 | 能处理多数普通社交，开始表达和拒绝 |
| 70-84 | 主动经营期 | 能建立关系、表达边界并被看见 |
| 85-100 | 灵活掌舵期 | 能按对象和场景切换策略，兼顾关系、边界和能量 |

### 人格匹配

使用八个独立结果原型向量，与用户的匹配刻度计算加权距离，距离最近者为结果。八个结果平等参与匹配，不拆成基础结果与强化结果。距离并列时以答案序列生成确定性指纹二次判定，不能依赖数组顺序。

八种结果：安静观察者、温和连接者、清晰表达者、边界守门人、稳定协作者、关系经营者、灵活适配者、低耗修复者。

每个结果必须独立提供：名称、别名/一句话定义、3 个关键词、画像、六维解析模板、核心优势、风险提醒、适合场景、3 条建议和 1 条专属提醒。建议必须包含触发场景、替代动作以及明确的时间或边界；专属提醒不得使用通用兜底或仅替换名称。

## 页面流程

`首页 / 测试码 → 40 道题 → 分析过渡 → 结果报告 → 保存报告 / 复制摘要 / 重新测试 / 好评返现`

- 正式测试码只通过 `POST /api/verify-code` 校验，前端不写死正确码。
- 产品 ID 固定为 `socialization-degree`。
- 答题页显示题号、进度、上一题；选项点击后进入下一题；最后一题生成结果。
- 结果页必须显示阶段、综合分、人格、完整六维雷达图、逐维度深度解析、综合评价、改进建议和工具箱。
- 结果页明确娱乐与自我观察免责声明。

## 分享海报

使用独立产品二维码，Canvas 生成高清 PNG。海报固定四区：身份区、六维数据区、三条建议区、二维码 CTA 区。六维全部展示，二维码绘制进 Canvas，生成后检查身份、数据、建议、对比度和二维码可识别性。

## 技术范围

在现有 `Evaluation-items` 仓库新增 `tests/socialization/` 下的题库、模型、页面、样式和模型测试；新增验证脚本；修改 Worker 的产品允许列表、测评首页入口和历史记录产品路由；准备独立卡片图片和二维码资源。沿用现有静态资源、会员/测试码、历史记录和海报生成模式，不引入新的前端框架或数据库表。

## 验收门槛

- 40 题、四选项、上一题修改和完整流程可用。
- 全选 A/B/C/D 至少出现 3 种人格结果。
- 随机模拟至少 100,000 份答卷，八种结果全部可达，单项命中率不垄断且保持在 3%-15% 目标区间；若初始语义矩阵无法满足，必须调整矩阵后再进入 UI 完善。
- 同一答案序列每次结果完全一致。
- 每种结果最高维度至少 80，最高与最低相差至少 25；不得六维全部低于 50 或完全相同。
- 八条专属提醒非空、互不重复、与人格匹配。
- 目标尺寸 `1440x900`、`1366x768`、`390x844`、`390x720`、`360x720`、`320x720` 无横向溢出、无明显重叠和控制台错误。
- 真实海报 PNG 内容完整，二维码实际可识别。
