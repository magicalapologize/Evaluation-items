# 天赋挖掘测试首页介绍区设计

## 目标

在天赋挖掘测试首页首屏入口之后补充一段紧凑、可信、易读的产品介绍，借鉴参考页的信息组织方式，但保持当前深色科技感视觉，不把首页拉成长营销落地页。

## 信息结构

介绍区固定包含四个信息单元：

1. **为什么做这项测试**：三个短卡片，分别回应“说不清自己擅长什么”“被单一标准衡量”“想找方向却缺少观察线索”。
2. **测试依据**：说明参考加德纳多元智能理论，将理论转译为八项用户可读的天赋维度，并明确结果是本次答卷的相对倾向，不是智力诊断或固定能力评级。
3. **你将获得什么**：四个短卡片，覆盖最佳天赋评估、八项天赋排序、活跃天赋组合、职业赛道与成长建议。
4. **适合谁**：三个短标签，覆盖自我了解、职业/副业探索、优势行动化三类用户。

区块末尾提供低强调的“了解测试方法”链接，首屏已有的测试入口仍是唯一主要 CTA。

## 视觉与响应式

- 延续首页现有海军蓝、青绿色、黄色强调色和粒子背景。
- 卡片使用半透明深色面板、细边框和短文案，不新增插画和评论模块。
- 桌面端采用“标题/理论说明 + 信息卡网格”的紧凑布局，新增高度目标约 560–680px。
- 手机端采用单列理论说明与 2×2 卡片网格，标签允许换行，新增高度目标约 600–800px。
- 所有文案保持自我观察与发展启发的可信表述，不承诺测评能决定职业或证明能力。

## 非目标

- 不修改题库、计分、测试码、会员逻辑、答题流程或结果页。
- 不加入用户评价、命中率、复杂长图或第二个高强调开始按钮。
